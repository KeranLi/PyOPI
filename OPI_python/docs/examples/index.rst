Examples
========

This section contains example scripts demonstrating various use cases of OPI.

Basic Examples
--------------

* **Simple Simulation** - Run a basic orographic precipitation simulation
* **Visualization** - Create plots of topography, precipitation, and isotopes
* **Parameter Sweep** - Explore how different parameters affect results

Advanced Examples
-----------------

* **Parameter Fitting** - Fit model parameters to observational data
* **Two-Winds Model** - Use two wind components for complex topography
* **Batch Processing** - Process multiple simulations in parallel

Example Scripts
---------------

The ``examples/`` directory in the source code contains ready-to-run scripts:

.. code-block:: bash

    cd OPI_python/examples
    python simple_example.py
    python fitting_example.py

Jupyter Notebooks
-----------------

Interactive tutorials are also available as Jupyter notebooks in the 
``notebooks/`` directory:

* ``01_quick_start.ipynb`` - Interactive introduction
* ``02_parameter_fitting.ipynb`` - Parameter optimization tutorial
* ``03_data_formats.ipynb`` - Working with different data formats
